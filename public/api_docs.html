Tour Management Public API v1

Authentication Required: All API requests must include the X-API-KEY header.
Demo Key: demo-api-key

Base URL

https://tour-management-web.onrender.com/api/v1/

Endpoints

GET tours.php

List tours or fetch a single tour.

Query Parameters:
  • id (optional): Get one tour by ID.
  • guide_id (optional): Filter by guide.
  • q (optional): Search by title/location.
Example Response: 
{
    "source": "db",
    "data": [
        {
            "id": 1,
            "guide_id": 3,
            "title": "Old Town Walking Tour",
            "location": "Prague, Czechia",
            "price": 25.00,
            "schedule_date": "2025-02-12"
        }
    ]
}
POST tours.php

Book a tour (creates a booking). Provide either user_id or email to identify the customer.

JSON Payload: 
{
    "tour_id": 1,
    "user_id": 10
}

// or with email-based guest creation
{
    "tour_id": 1,
    "email": "partner-guest@example.com",
    "name": "Guest from Partner"
}
Example Response: 
{
    "message": "Booking Created",
    "data": { "tour_id": 1, "user_id": 10, "status": "confirmed" }
}
GET places.php

List featured places.

Query Parameters:
  • q (optional): search in name/description
  • type (optional): e.g., City, Beach
  • continent (optional): e.g., Europe
  • climate (optional): e.g., Tropical
Example Response: 
{
  "source": "db",
  "data": [ { "id": 1, "name": "Paris, France", "type": "City" } ]
}
GET reviews.php

Read tour reviews.

Query Parameters:
  • tour_id (optional): reviews for a tour
  • guide_id (optional): reviews for a guide's tours
  • stats=true (optional with guide_id): averages
POST reviews.php

Create a tour review.

JSON Payload: 
{
  "tour_id": 1,
  "rating": 4.5,
  "comment": "Great tour!",
  "user_id": 10
}

// or with email-based user creation
{
  "tour_id": 1,
  "rating": 5,
  "comment": "Amazing",
  "email": "partner-reviewer@example.com",
  "name": "Partner Reviewer"
}
