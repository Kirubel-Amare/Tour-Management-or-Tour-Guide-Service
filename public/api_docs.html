Tour Management Public API v1

Authentication Required: All API requests must include the X-API-KEY header.
Demo Key: demo-api-key

Base URL

/tour_management/api/v1/

Endpoints

GET hotels.php

Search for hotels.

Query Parameters:
  • city (optional): City name to filter by.
  • q (optional): Search query.
Example Response: 
{
  "source": "external",
  "data": [
    {
      "id": "ext-1",
      "name": "Mock Placid Hotel",
      "location": "Paris, France",
      "price": 150
    }
  ]
}
POST hotels.php

Book a hotel room.

JSON Payload: 
{
  "hotel_id": "ext-1",
  "check_in": "2024-12-25",
  "check_out": "2024-12-30",
  "guests": 2,
  "roomType": "Standard"
}
GET restaurants.php

Search for restaurants.

Query Parameters:
  • city (optional)
  • cuisine (optional)
POST restaurants.php

Reserve a table.

JSON Payload: 
{
  "restaurant_id": "ext-r1",
  "date": "2024-12-25",
  "time": "19:00",
  "guests": 2
}
POST taxis.php

Order a taxi.

JSON Payload: 
{
  "pickup": "Hotel A",
  "destination": "Airport",
  "vehicleType": "standard"
}
